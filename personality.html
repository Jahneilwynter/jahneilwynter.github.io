Critical Essay: LLMS as tools and not a crutch

AI has been the new trend going around for the past few years, and basically everyone is using it, but recently it has become a problem in the learning environment. Students are using it to completely do their assignments, which is not the purpose of AI. It is a tool to help you learn, not a tool that should be used to do your work for you. I have been using LLMs like Gemini to help me learn a few things; for example, in doing this assignment, I've used Gemini to learn some key aspects of HTML and CSS while also doing my additional reading using websites and information on Moodle.
